SYSTEM FEATURES

Designed for Reliable Demonstration

Pre-trained AI Model

Uses a real pre-trained face detection and age/gender recognition model.

👤

Single Face Validation

The system rejects images containing multiple faces instead of selecting one arbitrarily.

⚡

Browser-Based Processing

The inference process runs directly in the browser using JavaScript and TensorFlow.js.

Core detection does not require user accounts or a database, ensuring user privacy.

About AI Predictions & Ethics

Gender and age outputs are estimates produced by the pre-trained model. Performance can vary depending on lighting, pose, image quality, occlusion, camera quality and the characteristics of the data used to train the model. This system is designed for educational and demonstration purposes.
